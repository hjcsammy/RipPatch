RipPatch 1.0.0
================

怎么用
------

  双击 RipPatch.cmd 启动。

  程序本体在 RipPatch\ 文件夹里。里面有 400 多个文件（.NET 运行时
  和依赖必须和 exe 放在一起，这是 .NET 的硬性要求），所以不要在里面
  翻找，直接用这个快捷方式就行。

  RipPatch.cmd 支持带参数，例如：
    RipPatch.cmd --web                用浏览器打开界面
    RipPatch.cmd --port 5199          固定端口
    RipPatch.cmd --web --no-open      只起服务，不自动开窗口

系统要求
--------

  Windows 10 1703+ / Windows 11，64 位。

  不需要安装 .NET —— 运行时已经打包在里面了。

  窗口模式需要 WebView2 运行时（Win10/11 一般自带；没有的话程序会
  自动改用浏览器打开，功能一样）。

第一次启动
----------

  可能会稍慢几秒，并且 Windows 可能弹出防火墙提示——那是本地服务
  在监听 127.0.0.1，选「取消」也能正常用。

  程序只监听本机回环地址，不向外网开放。

导出注意
--------

  整包导出会先清空你选的输出目录。请始终选一个专用的空文件夹，
  例如 D:\Exports\游戏名。

  单文件导出（右键 → 导出这个文件）不会删除任何东西。
